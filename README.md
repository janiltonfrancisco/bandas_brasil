`Projeto de Busca de Bandas de Rock Brasileiro`

Preview do Projeto

Este é um projeto web que permite buscar informações sobre algumas das maiores bandas de rock brasileiro: Paralamas do Sucesso, Legião Urbana, Engenheiros do Hawaii e Titãs.

Funcionalidades:

->Busca por nome da banda ou termos relacionados

->Exibição de informações sobre a banda:

->Foto

->Descrição

->Link para site oficial

->Player de áudio com música representativa

->Interface responsiva

-Tecnologias Utilizadas:

*HTML5

*CSS3

*JavaScript

-Como Usar:

. Digite o nome da banda ou um termo de busca no campo de pesquisa

. Pressione Enter ou clique no botão de pesquisa

. Visualize os resultados encontrados

*Bandas Disponíveis:

1. Paralamas do Sucesso

2. Legião Urbana

3. Engenheiros do Hawaii

4. Titãs

Estrutura de Arquivos

Copy

/projeto/

│── index.html        # Página principal

│── css/
│   └── style.css     # Estilos da aplicação

│── js/
│   ├── app.js        # Lógica da aplicação

│   └── dados.js      # Dados das bandas

│── img/              # Imagens das bandas

│── musicas/          # Arquivos de áudio

-Personalização:

Você pode facilmente adicionar mais bandas editando o arquivo dados.js e incluindo novos objetos no array dados com a mesma estrutura.
